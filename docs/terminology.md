# Терминология ConstraintLab

Все тексты ConstraintLab (задачи, разборы, сообщения проверки, справочник, интерфейс) пишутся
научно-техническим русским языком без жаргона. Английский термин допустим один раз в скобках
при первом упоминании, а также в именах команд, опций, отчётов и примитивов САПР.

| Не используем (жаргон, кальки) | Пишем |
|---|---|
| клок, клоки | тактовый сигнал, тактовые сигналы |
| клоковый (вход, буфер, дерево) | тактовый (вход, буфер, дерево) |
| первичный клок (primary clock) | первичный тактовый сигнал |
| генерируемый клок (generated clock) | производный тактовый сигнал |
| мастер-клок (master clock) | исходный тактовый сигнал |
| виртуальный клок | виртуальный тактовый сигнал |
| авто-клок (auto-derived) | автоматически выведенный тактовый сигнал |
| клоковый домен | тактовый домен |
| межклоковые пути | междоменные пути, пути между тактовыми доменами |
| констрейнты | ограничения (временны́е, физические), проектные ограничения |
| пин | вывод (ячейки, корпуса) |
| пад (pad) | контактная площадка |
| дизайн | проект |
| даташит | техническое описание |
| скважность 40 % (в смысле duty cycle) | коэффициент заполнения 40 % (скважность = T/τ = 2,5) |
| форвардинг клока | вывод тактового сигнала на внешний вывод (передача тактового сигнала приёмнику) |
| флаг | признак, однобитный сигнал |
| setup / hold (в тексте) | предустановка (setup) / удержание (hold); время предустановки t_su, время удержания t_h |
| relationship | соотношение фронтов, требование (requirement) |
| false path | ложный путь |
| multicycle path | многотактный путь |
| clock skew | перекос тактового сигнала |
| clock latency | задержка тактового сигнала |
| jitter | джиттер (фазовое дрожание) |
| launch / capture | фронт запуска / фронт захвата |
| handshake | квитирование |
| CDC | передача данных между тактовыми доменами |
| STA | статический временной анализ |
| песочница | интерактивная консоль |
| bitstream | конфигурационный файл (битовый поток) |
| fanout | коэффициент разветвления по выходу |
| trace | трасса печатной платы |

Остаются без перевода: имена команд и опций (`create_clock`, `-add_delay`), имена отчётов
(`report_timing`), имена примитивов (`BUFG`, `IDDR`, `MMCME2_ADV`), обозначения величин
(T, t_su, t_h, Tco), названия интерфейсов (DDR, LVDS, RGMII, SPI).
